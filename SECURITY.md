# Security

Please report a security issue privately, not in a public issue.

- Use GitHub's **Report a vulnerability** button on this repository's
  Security tab, or
- email info@rpotential.ai with "Security" in the subject.

We'll acknowledge your report and keep you updated while we look into it.

This repository holds only the plugin's skill text and the connector's
public address. It contains no credentials: you sign in to r.Potential
yourself when Claude first uses the connector.
